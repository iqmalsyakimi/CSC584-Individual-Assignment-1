\# Personal Profile Web Application



\## Project Description

Personal Profile is a Java-based web application that displays personal profile information through a web browser.



\## Technologies Used

\- Java

\- Java Servlet

\- JSP (JavaServer Pages)

\- HTML

\- Apache Tomcat

\- NetBeans IDE



\## Requirements

\- JDK

\- NetBeans IDE

\- Apache Tomcat Server



\## How to Run

1\. Open NetBeans IDE.

2\. Select File → Open Project.

3\. Locate and open the PersonalProfile project folder.

4\. Configure Apache Tomcat as the application server.

5\. Right-click the project and select Run.

6\. The application will open in your web browser.
